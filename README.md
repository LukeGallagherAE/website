# Adonai Electrical — Website

Modern website for [AdonaiElectrical.com](https://adonaielectrical.com) — a professional electrical services company.

## Stack

- Pure HTML5, CSS3, Vanilla JS — no frameworks, no build step required
- Google Fonts (Inter + Space Grotesk)
- Fully responsive (mobile-first)

## Features

- Animated hero with canvas particle system
- Stats counter with animated numbers
- Services grid (6 services)
- Portfolio with category filter
- Testimonials carousel (auto-plays, swipeable)
- FAQ accordion
- Contact form with success state
- Sticky nav with scroll-triggered highlight
- Mobile hamburger menu
- Scroll-to-top button
- 24/7 emergency banner

## Deploy

Drop these files on any static host (GitHub Pages, Netlify, Vercel, Squarespace file injection, etc.).

## Customise

- **Phone / email** — search for `1-800-ADONAI-1` and `info@adonaielectrical.com` in `index.html`
- **Colours** — edit CSS variables in `css/style.css` (`:root` block)
- **Photos** — replace `.portfolio-placeholder` divs with real `<img>` tags
- **Content** — all copy lives in `index.html`
